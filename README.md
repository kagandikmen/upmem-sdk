# UPMEM-SDK

UPMEM SDK is no longer downloadable on [sdk.upmem.com](https://sdk.upmem.com/) as of 2025-11-23. This repository is therefore intended to serve as an archive for people who want to continue using it in their personal workloads.

This repository uses Git Large File Storage (LFS). Visit [this page](https://docs.github.com/en/repositories/working-with-files/managing-large-files/installing-git-large-file-storage) for a nice tutorial on how to install it.

All SDK archives in this repository are scanned via [VirusTotal](https://www.virustotal.com/). Visit [this workflow page](https://github.com/kagandikmen/upmem-sdk/actions/workflows/virustotal.yml) for the latest scan.

**Disclaimer:** UPMEM SDK was made publicly available by UPMEM. This archive is provided for preservation and personal use only. All rights to UPMEM SDK belong to UPMEM (now part of Qualcomm); this repository claims no ownership and no affiliation with either.
